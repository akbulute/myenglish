# Your English Vocabulary - Language Learning Platform 🇬🇧

Modern, hızlı ve bilimsel yöntemlerle İngilizce kelime dağarcığınızı geliştirmeniz için tasarlanmış web tabanlı eğitim platformu. Aralıklı tekrar (spaced repetition) algoritması sayesinde kelimeleri ezberlemez, kalıcı olarak hafızanıza kazırsınız.

🔗 **Canlı Proje:** [vocab.emreyunusakbulut.com.tr](https://vocab.emreyunusakbulut.com.tr)

## ✨ Öne Çıkan Özellikler
* **Aralıklı Tekrar Mantığı:** Kelimeleri öğrenme durumunuza göre (Biliyorum, Emin Değilim, Bilmiyorum) sınıflandırma.
* **Toplu Veri Aktarımı:** Özel ayrıştırıcılar (Tab, Noktalı Virgül, Tire) kullanarak saniyeler içinde yüzlerce kelime ekleme.
* **Tam Responsive Tasarım:** Tüm mobil ve masaüstü cihazlarla kusursuz uyum.

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** React / Vite, Tailwind CSS
* **Routing & State:** React Router, Context API
* **Deployment & DNS:** Vercel, Custom Subdomain (IHS DNS Management)
